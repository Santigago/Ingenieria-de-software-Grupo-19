# Scripts de Base de Datos - Grupo 19

Directorio reservado para los scripts SQL (DDL, DML, migraciones) una vez que se definan los requisitos y modelo entidad-relación en el Documento 0 e Incremento 1.

---

## 🗂️ Convención Sugerida de Archivos

Cuando se definan las tablas, se recomienda estructurar los scripts de la siguiente forma:

1. `01_esquema_tablas.sql`: Definición de tipos y tablas.
2. `02_datos_prueba.sql`: Inserciones de prueba para verificar el sistema.
