# Documentación del Proyecto - Grupo 19

Documentos, diagramas de arquitectura, modelos de base de datos, entregables académicos e incrementos de desarrollo.

---

## 📁 Estructura del Directorio

```text
Documentos/
├── Documento_0/
│   ├── Diagramas/
│   │   ├── Casos_de_Uso/       # Diagramas DCU (.drawio, .png)
│   │   └── Procesos_BPMN/      # Modelos de procesos de negocio (.bpm, .drawio)
│   ├── Gestion/                # Planificación, Costo-Beneficio y Carta Gantt (.xlsx)
│   └── Entregables/            # Informe formal Documento 0 (.docx, .pdf, .pptx)
│
├── Incremento_1/
│   ├── Diagramas/
│   │   ├── Modelo_ER/          # Diagrama conceptual y lógico MERE
│   │   ├── Modelo_Fisico/      # Esquema relacional de tablas PostgreSQL
│   │   ├── Componentes/        # Diagrama de componentes del sistema
│   │   ├── Clases/             # Diagrama de clases de diseño
│   │   └── Navegacion/         # Árbol de navegación y flujo de vistas
│   ├── Entregables/            # Informe de entrega Incremento 1 (.docx, .pptx)
│   └── Evidencias/             # Videos demostrativos (.mp4, links) y capturas
│
├── Incremento_2/
│   ├── Diagramas/              # Diagramas de secuencia y refinamiento
│   ├── Entregables/            # Informe de entrega Incremento 2
│   └── Evidencias/             # Pruebas funcionales y demos
│
└── Recursos/                   # Pautas, rúbricas de evaluación y plantillas
```

> [!NOTE]
> os diagramas editables deben mantenerse en formato `.drawio` junto a su exportación visual (`.png` o `.pdf`) para facilitar su revisión y edición colaborativa.
